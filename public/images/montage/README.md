# Scene 12 — Memory Montage photos

Drop your photos here, replacing the files, using these exact names:

- `1.jpg` — "one of those days"
- `2.jpg` — "you + your impossible goals"
- `3.jpg` — "another race"
- `4.jpg` — "still you"

Any image format works as long as the filename matches (rename to `.jpg`/`.png`/`.webp`
and update the extension in `src/lib/media.ts` if you don't use `.jpg`).
Portrait-ish photos (roughly 3:4 or taller) look best since the montage crops them into
tall overlapping frames.
