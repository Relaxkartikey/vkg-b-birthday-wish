# Background music

Drop your song file here named `theme.mp3` (e.g. an mp3 of "10,000 Hours" —
Dan + Shay / Justin Bieber — that you have the rights to use) and it will
play when the center button is tapped. No code changes needed.

If you use a different filename or format, update `media.ts` → `ambientAudio`
in `src/lib/media.ts` to match.
